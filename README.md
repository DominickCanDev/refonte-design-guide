# refonte-design-guide

An English-language skill that provides a structured method for diagnosing,
planning, and implementing UX/UI redesigns across web and mobile interfaces. It
helps clarify user intent, information hierarchy, action priority, visual
coherence, responsive behavior, accessibility, and loading, error, empty, and
success states while preserving the product's business rules, functionality,
destinations, and visual identity.

## Contents

- `SKILL.md`: the autonomous method, decision criteria, examples, and delivery
  criteria.

## Usage

Install or reference this directory from your agent's skills directory. The
skill is intended for interface redesign requests, visual hierarchy
improvements, and journey clarification.

The method does not replace reading the target repository. Its components, data,
states, business rules, and project instructions remain the source of truth.
